# Modular gingerbread village (concept)

Concept stage: `modular_concept.png` shows six builds from one kit. No cut files exist yet.
Regenerate the render with `python3 tools/gingerbread_concept.py`.

## The kit

Everything is 3 mm plywood, press-fit with tabs and slots. Every wall edge uses the same tab spacing, so any
wall mates with any other wall, storey block or roof.

| Module | What it is | What it adds |
| --- | --- | --- |
| Core cottage | 2 gable walls, 2 side walls, 2 roof panels (about 120 x 95 x 120 mm) | A complete house on its own |
| Storey block | 4 plain walls with tabs top and bottom | Stack under a core roof for 2 or 3 floors |
| Side wing | Small 3-wall house that tabs into slots in a core side wall | L-shaped houses, porches, sheds |
| Wide block | Longer walls, roof ridge running side to side | Shops, bakeries, barns |
| Steep roof | Gable walls and roof at about 58 degrees | Towers, chapels |
| Chimney | 4 small pieces that sit on a roof slot | |
| Awning + posts | Scalloped panel and two candy-cane posts | Shop fronts, porches |
| Icicle trim | Bargeboard that clips on the roof edge | The iced-eave look; leave it off for a plain house |
| Base plate | Plate with slots for the walls and puzzle tabs on the edges | Plates lock together into a village |
| Scenery | Slot-together trees, picket fence, gingerbread figures | Stand in slots in the base plates |

## Customising

- Faces are interchangeable: each wall comes in several versions (round, square, arched or heart windows; door or no door).
- Decorations are separate glue-on pieces: snowflake, wreath, star, tree, candy canes, clock, name plaque.
- The name plaque and door can be engraved with a family name or house number.
- Window holes are open, so a battery tea light inside makes the house glow.
- Cream parts in the render (icicles, decorations, scenery) are the same plywood painted white, or left natural.
